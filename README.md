# TradPlus Google IMA Adapter Swift Package

Swift Package Manager support for the TradPlus Google IMA adapter (15.12.0).

## Installation

```text
https://github.com/tradplus/TradPlusAdSDK-SPM-GoogleIMA.git
```

```swift
.package(url: "https://github.com/tradplus/TradPlusAdSDK-SPM-GoogleIMA.git", exact: "15.12.0")
```

Third-party dependency: Google IMA SDK `3.27.4`.

## Notes

- This package automatically resolves `TradPlusAdSDK` 15.12.0.
- Add `-ObjC` to the app target's `Other Linker Flags` if required.
